Hier sind die Speicherorte des Command & Conquer RTS Projekts:

1. Unity Projekt & Skripte:
Der komplette Quellcode und die Unity-Szenen liegen in diesem Ordner (E:\unity antigravity\My project\).
Die C# Skripte von Claude befinden sich unter: E:\unity antigravity\My project\Assets\RTS\Scripts\

2. 3D Modelle (aus Blender):
Die fertigen, texturierten 3D-Modelle wurden von Claude aus Blender exportiert.
Sie liegen als .fbx-Dateien in: E:\unity antigravity\My project\Assets\Models\

3. GitHub Backup:
Alles zusammen (Skripte + Modelle) wurde über Git gesichert und hochgeladen auf:
https://github.com/Phillboo/CommandAndConquer-Unity

WICHTIG: Die rohe .blend-Quelldatei wurde von Claude bei der Generierung wahrscheinlich nur im Arbeitsspeicher gehalten und direkt als .fbx nach Unity geschoben. Um die Rohdatei zu sichern, drücke bitte Strg+S in deinem aktuell offenen Blender-Fenster und speichere sie z.B. in den "Models"-Ordner dieses Projekts.
